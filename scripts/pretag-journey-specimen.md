# A Room to Walk Through

A short opening paragraph sets the measure for the rows
beneath it, and gives the outline rail a first rung.

## The Plain Block

Every line in this block is deliberately plain prose.
No emphasis, no code span, no list marker, no heading.
The journey sweep parks its caret inside this block and
moves it two rows, so the only thing that may change
between the two frames is the caret itself.
A selection is drawn across the same rows for the same
reason: one difference at a time, and a control row far
enough below to stay untouched by either of them.
The block runs long enough that a control row exists.
It also keeps every line inside a narrow measure.

## Voice

Prose carries **weight** through emphasis and a little
`inline code`, never a rainbow of color.

- A short list settles the eye
- Each line stays plain
- The room holds still
