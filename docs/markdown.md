# awl docs — Markdown render, WYSIWYG conceal & formatting commands

> Read before touching `markdown/`, `actions/format.rs`, `actions/link.rs`, heading sizes/row heights, or any conceal/reveal behavior.

## Markdown styling (`markdown/` + `render.rs`) — dim the markup, style the content

- Syntax characters recede to `muted` (present + editable); content gains structure: bold weight, italic, mono+tint code, link text in content ink (brackets/URL recede), **headings = larger size per level (Ladder J: 1.6/1.3/1.15 via `markdown/headings.rs::type_scale`), no interactive accent; weight is per-world data** — `Theme::heading_bold` (one bit: `##`/`###` bold, `#` never; serif worlds regular, mono/sans worlds bold; law `heading_bold_worlds_shape_bold_in_their_own_family`).
- Gated by `is_markdown` — a no-path scratch/note buffer reads as markdown from the first keystroke; a saved file by `.md`/`.markdown` only. A `.rs`/`.txt`/`.env` file renders byte-identically.
- `markdown::spans(text)` (pulldown-cmark) → `(range, MdKind)` laid as base per-span `AttrsList` under the CJK spans (same seam). Pure/deterministic, re-parsed each reshape. Sidecar `md_spans`.
- **Heading size = variable row heights:** keyed off leading `#` count. The scroll↔pixel math reads a per-row geometry cache (`RowGeom`, `render/rowgeom.rs`, delegated from `TextPipeline` via `row_top_px`/`row_height_px`/`total_doc_height`), not a constant `LINE_HEIGHT`; block caret scales by `cursor_scale()`. A zoom/DPI change or `is_markdown` flip rebuilds attrs (`restyle_all_lines`).
- **Fenced code syntax:** the info-string language highlights the body via `syntax::spans`, translated to doc offsets as `MdKind::CodeSyntax` (role color wins the flat Code tint, mono face kept). Unknown/indented → plain mono.
- **`==highlight==`** (Obsidian convention, not CommonMark): a warm wash behind full-ink text; hand-rolled scan for exactly-two `=` (a bare `=`/`===`/cross-line stays inert). **Task lists / rules / word-count readout:** `- [ ]`/`- [x]`, `---` thematic break (dim quad across the column), a dim bottom-right word-count + reading-time (markdown only).
- **No setext headings — `---`/`***`/`___` always draw as the rule:** awl's heading ladder is ATX-only (`#`). A dash underline directly under a paragraph is a setext H2 to CommonMark, but a run of 3-or-more qualifies as a thematic break independently of what precedes it, and DECIDED always renders as one — `spans`' `Tag::Heading` arm pushes a real `MdKind::Rule` for exactly the underline's bytes, leaving the title line above it as plain body text (never sized/bolded as a heading). `***`/`___` were never ambiguous with setext (only `-`/`=` are valid underline chars) and always drew as the rule already. A too-short underline (a bare `-`/`--`, valid CommonMark setext but under the 3-run floor) and a setext H1 (`===`, not a thematic-break syntax) are untouched — plain, unstyled text.

## WYSIWYG conceal-on-cursor (`markdown/` + `render/spans/` + `render/rects.rs`)

- **The rule:** "if the caret OR an active selection touches that line, show the actual markdown; otherwise show the preview" (widened 2026-07-22 — selection reveal — from the original caret-only rule). `MdKind::ConcealMarkup(ConcealKind)` renders dim like `Markup` until concealed by `add_wysiwyg_conceal_spans`. Kinds: Heading / Emphasis / Code (inline backticks) / Highlight / Link / Footnote / BareUrl are line-scoped; Fence is block-scoped (reveals iff the caret is anywhere in the block, or the selection touches any line inside it; a body line is never concealed).
- **Bare URLs** (`markdown/spans/detect.rs::bare_url_ranges`/`bare_url_split`): a plain-text `http://`/`https://` URL — never one already inside `[text](url)` or an angle-bracket autolink, both of which are `ConcealKind::Link` instead — gets TWO flanking `ConcealKind::BareUrl` spans, the link-plumbing precedent one event later: a leading SCHEME span (always conceals) and a trailing TAIL span (from the first `/` or `?` after the authority — conceals ONLY if present, so `https://example.com` alone gets no tail and no ellipsis promise). The authority between them (host, optional `:port`, `www.` kept verbatim) carries no span at all — real, always-visible text, never a painted substitute. Off-cursor the tail's first byte is letter-spacing-forced to a reserved slot (`render/spans/conceal/bare_url.rs::bare_url_ellipsis_slot`, sized off `line_height` alone) and a quiet "…" paints into it as its own ornament family (`render/layers/ornaments/bare_url.rs::BareUrlEllipses`, `TextPipeline::bare_url_marks`) — the exact `footnote_number_slot`/`FootnoteNumbers` shape, minus the "which number" payload. On the caret's own line (or a touching selection) both flanking spans reveal and the full URL shows raw, painting no ellipsis.
- **Followable-span underline (2026-08-29 decision, `render/spans/colors.rs` + `render/rects.rs`):** ONE grammar for every span a person can follow — a named `[text](url)` link's `MdKind::LinkText` and a tamed bare URL's `MdKind::BareUrlText` (spans the WHOLE match, scheme through tail, pushed FIRST by `push_bare_url_spans` so the flanking `ConcealMarkup(BareUrl)` scheme/tail spans still win their own bytes on overlap) both enrol the SAME `render::rects::Bucket::LinkUnderline`, drawn by ONE pipeline (`link_underline_pipeline`) at ONE band (`spans::link_underline_band`, `Logical` units — the `strike_line_band` precedent, never a bare device-pixel constant). A hairline at the text's own muted ink (`link_underline_ink` = `strike_ink` = `th.muted`), SOLID — every world's `muted` is `Srgb::rgb(...)`, always `a: 0xFF` — never an alpha-blended wash (the `decorative_wash: Off` ban `nit_underline_srgba` already learned, sidestepped entirely here by never being translucent to begin with). Sits at the BASELINE (`LINK_UNDERLINE_V_FRAC = 0.92`, near the bottom of the glyph cell), distinct by position and shape from strike (through the middle) and spell (wavy, below). **DECIDED: the underline PERSISTS while the caret's line reveals raw markdown** — it is content styling riding the visible run's own glyph extents (`row.xs`, the SAME collapsed/revealed advances the conceal mechanism already produces), not the markup/scheme plumbing's OWN reveal-on-cursor state, so it needs no separate persist/drop branch at all: off-caret it hugs the tamed authority + reserved ellipsis slot, on-caret it re-hugs the fully revealed text. Reasons: (1) it mirrors the named-link precedent already shipped since 2026-07-22 ("content styling, not marker conceal") — a link-only carve-out would be the second rule, not the first; (2) every other content-styling span (Bold, Italic, Highlight, Strikethrough) already survives the caret landing on its line, so PERSIST keeps "content styling stays, only markup SYNTAX reveals" as one coherent rule instead of adding link-family exceptions; (3) the caret's own line is exactly where a person is reading or about to follow that link — dropping the affordance there removes it at the one moment it is most useful.
- **Selection reveal (2026-07-22):** the ONE owner `wysiwyg_reveals` (`render/spans/conceal.rs`) takes an additional `selection_touch: Option<&Range<usize>>` — the document byte extent of every LINE the active selection touches (`selection_touch_bytes`, column-agnostic `l0..=l1`), computed once per reshape/refresh and threaded alongside the caret line into every span/line decision, never re-derived per kind. A selected TABLE is the motivating case: `ConcealKind::Table`'s own in-place reveal decision stays `false` (unchanged — a table's source never un-conceals in place), but `TextPipeline::prepare_table_xray`/`prepare_table_grid` extend the SAME caret-only x-ray float to every table row the selection touches, so a selected table shows its raw `|` source row-by-row instead of just the caret's own row. The legacy (pre-`ConcealKind`) rule/bullet conceal (`add_rule_conceal_span`/`add_bullet_conceal_span`) widens identically via the same line-overlap test in `build_line_attrs`, so a selected bulleted list also reveals its raw markers. **Tripwire:** `refresh_rule_conceal`'s skip-gate compares `self.selection` alongside `self.cursor_line` (a NEW `last_conceal_selection` field) — a selection change that doesn't move the caret's own LINE (e.g. a Shift-click keeping the caret's line but moving the anchor, or a `C-g` clearing the mark) would otherwise be skipped by a caret-line-only gate and serve stale (still-revealed or still-concealed) `row_geom`.
- ‼ **A concealed span's metrics are ABSOLUTE, so a scale change must rebuild them.** Pairing the
  near-zero font size with the line's own `line_height` bakes a length that **survives cosmic-text's
  relayout and then wins over the buffer's new metrics** — so a display move to a different scale factor
  left the row pitch at the value it was shaped at (32.0 at dpi 1, 1.5, 2 and 3 alike) on any markdown with
  concealed markup and **no heading**. `set_dpi` used to rebuild line attrs only for headings; **a heading
  is not the only construct with absolute per-span metrics, and conceal is the other one.** It now restyles
  unconditionally, and `row_pitch_dpi_law` grades a scale change against a pipeline born at that scale.
  ⚠️ **The band gives it away by falling:** the band scale is row-height over line-height, so a stale row
  over live metrics reads as the decoration SHRINKING as the display gets denser. ⚠️ **No capture can see
  this axis** — every capture builds a fresh pipeline, so this is live-only by construction.
- **True zero-width conceal:** a concealed span overrides `metrics` to a near-zero font size (`CONCEAL_ZERO_WIDTH_FONT_SIZE = 0.01`) — collapsing its pixel advance, not just its color — with its line-height half set to the row's real height. Works because cosmic-text computes advance at layout time and `Attrs::compatible` ignores `metrics_opt` (shaping runs unaffected). Accepted cost: the line reflows the instant the caret enters and markers reveal (line-local only). **Tripwire:** `refresh_rule_conceal` now invalidates `row_geom` alongside its reshape (reveal can change advances, not just color — the stale-memo bug).
- **Two washes (both `wysiwyg_on()`, opaque `base_200` value-step quads):** a pill behind inline code, a panel spanning the whole fenced block (always present — it is the block's affordance; only marker text is caret-gated). **Seam fix:** `render::rects::merge_row_bands` sizes each row to its full `line_height` and merges vertically-contiguous same-bucket rows into fewer taller quads (fence panel → one quad/block), so antialiasing only happens at true outer edges, never an internal row boundary.
- **Config `wysiwyg` (sticky bool, default on):** `false` is a total no-op (byte-identical to pre-round always-visible markup). Sidecar `wysiwyg { on, concealed }` shares the one reveal rule (`wysiwyg_reveals`) with the renderer.

## Markdown formatting commands (`actions/format.rs`) + Links v2 (`actions/link.rs`)

- **Eleven toggle commands**, each one undoable edit, markdown buffers only. Block: Blockquote, Bullet/Numbered/Task List, Heading, Code Block. Inline: Bold (Cmd-B), Italic (Cmd-I), Inline Code (Cmd-E), Highlight, Strikethrough. The rest are palette-only, all rebindable. The contextual formatting popover fires these same actions; it is the bounded pointer bridge described in `DESIGN.md` §6, not a separate formatting model.
- **Insert link… (Cmd-K, markdown only):** `link::plan` decides purely from state — selection wraps `[sel](url)`; caret in an existing link edits (prefills that link's URL); else inserts `[](url)`. A kill-ring URL prefills iff it looks like one. Cmd-K stays Insert-link on Mac unconditionally; on Linux `C-k` stays kill-line (see docs/config.md's tripwire).
- **Insert footnote (palette, markdown only):** inserts a collision-free numeric reference at the caret or selection end, appends its definition after a block boundary, and leaves the caret ready to type definition prose. Footnote display numbers follow first reference appearance; labels remain source IDs rather than display numbers. `[^label]` and continued indented definition lines are the widely used GitHub-compatible extension, not core CommonMark or the formal GFM specification. Activating a composed reference jumps through the same line-placement and fold-reveal path as outline navigation.
