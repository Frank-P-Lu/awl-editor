# Ornament Cabinet review

Historical candidate reference for queue item 645. The user approved the revised
Site sets on 2026-09-12; the exact implementation roster now lives in queue.md
item 645 and supersedes every proposal or reservation below.

The user supplied an older Cabinet and explicitly requires list bullets and
dividers to use different symbols within each world. Its historical approval
labels are reference material, not evidence of current implementation. The
recently approved per-world Nishiki checkbox assignments in 644 remain the task
design. This review does not revive the Cabinet's older pictorial task pairs.

## Selection rules

Latest user review: Mulga's one/two/three stroke trio is approved. Replace Tawny's
third harvest glyph, Gumtree's dog-like paw print, Quokka's rose, the shoreline
shell, Bowerbird's collected-object trio and Magpie's pictorial pencil. The user
accepts sharing an entire set rather than maintaining sets that differ by only
one glyph. New replacements remain proposals for review, not approved picks.
The updated Site auditions Tawny/Potoroo as chestnut/seedling/butterfly; Gumtree
as bird/butterfly/leaf; Quokka as wine glass/cup/crossed swords; Bombora/Mangrove
as anchor/sailboat/spoked wheel; Bilby/Mopoke/Bowerbird/Kite as star/cloud/comet;
and Magpie as reference mark/separation mark/three-dot therefore mark. These
latest proposals supersede the corresponding starting points in the table below.

- Separate bullet, divider and task vocabularies within each world, including
  components of multi-glyph dividers. Cross-world reuse is acceptable.
- Bullet depth siblings need visibly different silhouettes and comparable ink
  weight at actual bullet size. Different Unicode values alone prove neither.
- Keep the large divider character. Do not solve a weak bullet by shrinking or
  changing an otherwise sound divider.
- Check against actual fold, quote, footnote and chrome glyphs. The Cabinet's
  surface census is historical; for example, closing quotes now exist and the
  footnote ladder uses daggers, pilcrow and section signs.
- Render from verified Nishiki outlines. Descriptive names without codepoints
  remain unresolved candidates; never guess a private-use assignment.

## Ambiguities in the supplied reference

- Gumtree's prose both shelves and keeps the fish, and describes a sequence that
  differs from the current dash/star/underscore order. Use the current roster as
  baseline and label every proposed swap.
- Quokka both stays with its incumbent suits and is described elsewhere as moving
  on. Keep the incumbent divider baseline unless a concrete replacement is chosen.
- The Cabinet's claim that proposed symbols are bundled must be checked against
  the current Awl Marks cmap; full upstream coverage is not bundled coverage.
