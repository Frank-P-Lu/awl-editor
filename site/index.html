Unpack the archive and run the binary. Nothing is installed.

tar xzf awl-0.11.0-linux-x86_64.tar.gz
cd awl-0.11.0-linux-x86_64
./awl notes.md

Check it against the release's SHA256SUMS first with sha256sum -c SHA256SUMS. awl needs a working Vulkan driver, fontconfig, libxkbcommon, and Wayland or X11; the archive's README.txt names the packages per distro. A signed macOS build is not ready yet.
